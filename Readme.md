# Engineering Playground

A collection of software engineering explorations, hands-on experiments, and learning notes spanning data structures & algorithms, .NET internals, system design, performance engineering, cloud technologies, and AI/ML concepts.

## Purpose

This repository serves as a personal engineering lab for:

- Practising data structures and algorithms
- Exploring software design patterns and architecture
- Investigating .NET runtime and performance concepts
- Building AI and machine learning solutions
- Experimenting with cloud-native technologies
- Documenting technical learnings and problem-solving approaches
